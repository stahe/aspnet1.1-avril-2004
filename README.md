# Développement Web avec ASP.NET 1.1

➡️ **Cours en ligne :**
[Développement Web avec ASP.NET 1.1](https://stahe.github.io/aspnet1.1-avril-2004/)

## Présentation

Ce document constitue un **support pédagogique** destiné aux étudiants et ne prétend pas être un cours exhaustif. Certains sujets nécessitent l'accompagnement d'un enseignant et plusieurs thèmes du développement web n’y sont volontairement pas abordés. 

Ce support s'inscrit dans une série de documents consacrés au **développement web**, déjà exploré par l’auteur à travers deux technologies :

* **Java**
* **PHP**

Ces documents partagent une **structure pédagogique similaire**, permettant de comparer les différentes technologies à travers des exemples analogues.

## Approche pédagogique

Contrairement à de nombreux ouvrages consacrés à ASP.NET, ce support ne se concentre pas immédiatement sur l'idée selon laquelle une application web ASP.NET peut être développée comme une **application Windows**.

Dans la littérature ASP.NET classique :

* l’interface utilisateur est souvent construite dans des IDE comme **Visual Studio .NET** ou **WebMatrix**
* des **contrôles graphiques** sont déposés dans une interface visuelle
* ces contrôles possèdent **propriétés, méthodes et événements**

Dans ce document, ces concepts sont volontairement présentés **plus tard dans le cours**, car ils sont jugés importants mais **non fondamentaux** pour comprendre le développement web.

## Objectif principal

La première partie du document met l'accent sur les **fondements du développement web**, indépendants de la technologie utilisée (Java, PHP ou ASP.NET).

Une attention particulière est portée à l’architecture :

**MVC — Modèle / Vue / Contrôleur**

Cette architecture est fréquemment recommandée pour concevoir des applications web structurées et maintenables.

Cependant, l’approche MVC s’accorde relativement mal avec la vision d’ASP.NET consistant à concevoir une application web comme une application Windows. Pour cette raison, les mécanismes spécifiques d’ASP.NET visant à augmenter la productivité sont abordés **dans la seconde partie du cours**.

## Outils utilisés

Le document privilégie exclusivement des **outils librement disponibles sur Internet**, afin que les étudiants puissent :

* les télécharger facilement
* installer l’environnement sur leur machine personnelle
* reproduire et expérimenter les exemples présentés

Une annexe intitulée **« Les outils du web »** explique comment récupérer et installer ces outils.
